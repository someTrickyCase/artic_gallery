This is a [ARTIC Gallery](https://artic-gallery.netlify.app) project that used a[`Chicago Institue of Art API`](https://api.artic.edu/docs/).
Here you can search, view and save some of over than 10,000 masterpieces, created by most famous and acclimed artists.

## TechStack

Technologies uses in the project are part of a fairly popular front-end technology stack.
Used:
-framework: ['Next.js'](https://nextjs.org/)
-state manager: ['Zustand'](https://zustand.docs.pmnd.rs/getting-started/introduction)
-data fetching and caching: ['SWR'](https://swr.vercel.app/)
-css framework: ['TailwindCSS'](https://tailwindcss.com/)

Deployed on ['Netlify'](https://www.netlify.com/)

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Inter](https://vercel.com/font), a new font family for Vercel.
