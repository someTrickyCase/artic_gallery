# 🎨 Галерея искусств

[Открыть галерею](https://artic-gallery.netlify.app)

Виртуальная галерея, где можно поглазеть на шедевры из коллекции Чикагского института искусств — без очередей, билетов и смотрителей за спиной.

## Что можно делать:
- 👁️ **Смотреть** — сколько угодно, хоть в упор
- 💾 **Сохранять** — в избранное, а не в карман
- 🔍 **Узнавать** — все подробности о произведениях
- 🎯 **Искать** — то, что по-настоящему цепляет

## Что нельзя:
- 🙅 **Трогать руками** — даже если очень хочется
- 📸 **Фотографировать** — со вспышкой тем более

## Технологии под капотом
- Next.js
- TypeScript
- Tailwind CSS
- Zustand
